# SQ MARKET — сайт

Статичный сайт-презентация формата SQ Market. Без сборки, без npm, без фреймворков:
открывается как обычный `index.html`, заливается на любой хостинг перетаскиванием папки.

---

## Как запустить локально

Просто откройте `index.html` в браузере. Карта 2ГИС и шрифты требуют интернета.

Если хочется «как на сервере» (правильные пути, без ограничений браузера на локальные файлы):

```bash
python -m http.server 5177 --directory "D:/CC/projects/SQ Plov/site"
```

Потом откройте http://localhost:5177

## Телефон — это отдельная версия, а не сжатый десктоп

Все отличия собраны в одном файле `assets/css/mobile.css` и включаются ниже 860 px.
То же число продублировано в `core.js` (`SQCore.isMobile`) — от него зависят
не только стили, но и поведение:

| Раздел         | Десктоп                          | Телефон                                         |
|----------------|----------------------------------|-------------------------------------------------|
| Что внутри     | сетка из 12 карточек             | карусель со свайпом и точками-страницами        |
| Твой день      | список + большой кадр справа     | список, нажатие открывает окно с фотографией    |
| Ассортимент    | вкладки категорий                | аккордеон: категории свёрнуты, секция короткая  |
| Интерьер       | мозаика 12 плиток                | карусель со свайпом и точками                   |
| Адреса         | карта рядом со списком точек     | карта открывается окном по нажатию на адрес     |
| Окна           | по центру экрана                 | выезжают снизу, как в приложениях               |
| Футер          | три колонки                      | две колонки, компактные отступы                 |

Если меняете границу 860 px — поменяйте её в обоих местах, иначе стили и поведение
разойдутся.

## Частые правки

### Поменять телефон, город, соцсети

`assets/js/data.js` → блок `config`. Телефон подставится сразу в шапку, футер,
контакты и в ссылку WhatsApp. `phoneRaw` — тот же номер без плюсов и пробелов.

Как только впишете `instagram` или `tiktok`, иконки сами появятся в футере.

### Добавить или убрать пункт «Что внутри»

`data.js` → массив `inside`. Скопируйте соседний блок `{ ... }` и поменяйте текст.
`icon` — имя из `icons.js` (`coffee`, `bread`, `wifi`, `clock`…). `image` — путь к фото,
оно откроется во всплывающем окне.

### Поменять ассортимент и добавить цены

`data.js` → массив `menu`. У каждой позиции есть необязательное поле `price`:

```js
{ name: "Плов", desc: "Фирменная позиция", price: "1 290 ₸" },
```

Как только цена появится — она отрисуется справа в строке вместо метки «Хит».
Сейчас цен нет намеренно: в списке указаны категории и типовые позиции формата,
их нужно заменить на реальный ассортимент перед запуском.

### Добавить третий магазин

`data.js` → массив `branches`. Нужны:

* `firmId` — из ссылки 2ГИС вида `2gis.kz/astana/firm/<ID>`;
* `lat` / `lon` — координаты (есть в той же ссылке, но в порядке `долгота,широта`);
* `link` — короткая ссылка `go.2gis.com/…` на карточку.

Точка сама появится в списке, в футере и в переключателе карты.

### Поменять фотографии

Положите файл в `assets/img/interior/` и пропишите имя в `data.js`.
Для галереи нужны две версии — крупная в `interior/` и лёгкая в `thumb/` с тем же именем.
Оптимальные размеры: 1400 px по длинной стороне для крупной, 700 px для превью.

### Поменять фирменные цвета

`assets/css/tokens.css`, самый верх. Цвета берутся из брендбука:

| Переменная        | Цвет      | Где применяется                      |
|-------------------|-----------|--------------------------------------|
| `--brand-green`   | `#0a6b3e` | основной, кнопки, «SQ»               |
| `--brand-orange`  | `#ff8a00` | акцент, метки, «MARKET»              |
| `--brand-black`   | `#1a1a1a` | тёмные секции                        |
| `--neon`          | `#b9f227` | точечная подсветка, как в интерьере  |

Ниже в том же файле лежит блок `[data-theme="dark"]` — это ночная тема,
она включается кнопкой-луной в шапке и запоминается в браузере посетителя.

## Форма заявки

Сейчас форма работает без сервера: после проверки полей она открывает WhatsApp
с уже набранным сообщением и показывает окно «Заявка принята».

Если появится почтовый приёмник (Formspree, Getform, свой скрипт) — впишите его адрес
в `data.js` → `config.formEndpoint`, и форма начнёт слать данные туда.

## Карта

Используется официальный виджет 2ГИС — без API-ключа и регистрации. Он отдаёт
настоящие тайлы 2ГИС и карточку организации с адресом, телефоном и способами оплаты.
Клик по адресу слева переключает карту между филиалами.

**Кнопка «Маршрут» работает по-разному на телефоне и на компьютере.**

*Телефон.* Это обычная ссылка на `2gis.kz`, никакого перехвата в коде нет.
Телефон сам открывает её в приложении 2ГИС, если оно установлено (так работают
app links), и приложение строит маршрут от текущего положения. Приложения нет —
откроется сайт 2ГИС.

*Компьютер.* Приложения нет, поэтому сайт спрашивает у браузера местоположение
и открывает 2ГИС в новой вкладке с уже построенным маршрутом. Геолокация
запрещена — откроется карточка маршрута, и 2ГИС предложит определить место сам.
Браузеры отдают геолокацию только на HTTPS и на localhost: пока сайт открыт по
`http://192.168.0.4:5177`, всегда сработает второй сценарий.

Формат ссылки 2ГИС (подобран опытным путём, документации нет):
`/directions/points/<долгота А>,<широта А>|<долгота Б>,<широта Б>;<id организации>`.
Ведущий `|` означает «точка А пустая».

Если понадобится жёстко открывать именно приложение — есть схема
`dgis://2gis.kz/routeSearch/rsType/car/to/<долгота>,<широта>`, но при
отсутствии приложения телефон покажет ошибку, поэтому её не используем.

**Почему сама карта не кликается.** У виджета осталась старая начинка: внутренние
ссылки он собирает как `2gis.ru/moscow/...` и открывает пустую страницу, а в углу
пишет «Посмотреть на карте Москвы». Исправить это со стороны сайта нельзя — виджет
чужой. Поэтому кликов ему не даём (`pointer-events: none`), сверху лежит своя панель
с кнопками «Маршрут» и «Открыть в 2ГИС», которые ведут на правильный `2gis.kz`.
Побочная польза: на телефоне карта больше не «съедает» прокрутку страницы.

Город задаётся в `assets/js/map.js` (`const CITY = "astana"`), масштаб — там же (`ZOOM`).

Если понадобится полноценная карта с зумом и своими метками — это 2GIS MapGL,
для него нужен бесплатный ключ с dev.2gis.ru.

## Что убрано намеренно

* **Круг за курсором.** Был в первой версии, Дамир попросил убрать — удалён
  вместе со стилями и кодом.
* **Пакет-персонаж на главном экране телефона.** Он перекрывался с плашкой
  цифр и просвечивал сквозь неё. Персонаж целиком показан ниже, в разделе
  «Персонаж бренда». Вернуть можно одной строкой в `mobile.css`
  (`.hero__mascot { display: none }`).
* **Параллакс на телефоне.** Из-за него картинки «плавали» при прокрутке.
* **Заезды блоков слева и справа на телефоне.** Осталось короткое появление снизу,
  иначе страница визуально «каталась» по горизонтали.
* **Эффекты наведения на тач-экранах** (`@media (hover: none)`) — на телефоне
  состояние `:hover` залипает после нажатия, и кнопка остаётся «подсвеченной».

## Браузер показывает старую версию после правок

В `index.html` к стилям и скриптам приписан номер версии: `tokens.css?v=10`.
Поменяли файл — увеличьте цифру у всех строк на единицу (найти и заменить `?v=10`
на `?v=11`), и браузеры подхватят новую версию. Без этого посетители с открытым
сайтом могут ещё какое-то время видеть старые стили.

## Что нужно обновить перед запуском

1. **Статусы точек.** В `data.js` → `branches` у обеих точек стоит «Скоро открытие»
   (так они сейчас числятся в 2ГИС). После открытия поменяйте на «Открыто».
2. **Ассортимент.** Позиции в `menu` — типовые для формата, их нужно заменить на реальные.
3. **Соцсети и почта.** Пустые поля в `config` — иконки и строка почты появятся автоматически.
4. **Домен и аналитика.** В `index.html` в `<head>` стоит `og:image` относительным путём —
   после привязки домена лучше указать полный адрес, чтобы превью работало в мессенджерах.

## Куда выложить

Любой статичный хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages,
хостинг с обычным FTP. Заливается вся папка `site/` целиком, точка входа — `index.html`.

Через GitHub Pages:

```bash
git init
git add .
git commit -m "SQ Market site"
git branch -M main
git remote add origin <адрес репозитория>
git push -u origin main
```

Затем в настройках репозитория: Settings → Pages → Source: `main` / корень.

## Доступность и производительность

* Все всплывающие окна закрываются на `Esc`, фокус не убегает за пределы окна.
* В лайтбоксе работают стрелки клавиатуры и свайп на телефоне.
* Все анимации выключаются, если в системе включено «уменьшить движение».
* Фото грузятся лениво, карта — только когда посетитель доскроллил до неё.
